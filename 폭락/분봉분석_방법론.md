### v1 → v2: Look-ahead Bias 제거
v1의 `gaussian_filter1d`는 비인과적(non-causal) 필터로 미래 데이터를 참조했습니다. v2에서 인과적 EMA로 교체.

### 1.3 Dual Grid 설계

Phase 3과 Phase 4는 **서로 다른 시간축**에서 독립적으로 분석하고, Phase 5에서 결과를 교차 검증합니다.

```
1분봉 OHLCV (4종목)
    │
    ├──────────────────────────┐
    ▼                          ▼
[Phase 3: Volume Bar Grid]   [Phase 4: 1-Min Grid]
종목별 독립, 이벤트 기반        4종목 동시, 시간 기반
    │                          │
    ▼                          ▼
Volume Bar 구성                1분봉 그대로 사용
Kyle's λ, VPIN, Amihud        Cross-sectional Z-score
종목별 바닥 시점 탐지            Adaptive Kalman + Rolling OLS
(정확한 시각 기록)              β 계수 시계열
    │                          │
    └────────┬─────────────────┘
             ▼
      [Phase 5: 교차 검증]
      + 인과적 1차/2차 미분 제로크로싱
      + 확률적 제로크로싱 예측 (v3 추가)
      + 종목 간 선행/후행
```

**왜 분리하는가 (Time vs Event 충돌 문제)**:
Volume Bar는 종목마다 봉 완성 시점이 다릅니다. 삼성전자는 10:03에 봉이 완성되고 현대위아는 10:08에 봉이 완성되면, 매 1분마다 정확히 횡단면 비교(Cross-sectional Z-score)를 하려면 시계열의 기준점을 어떻게 맞출지 문제가 됩니다.

Zero-Order Hold(매 정각마다 가장 최근 완성된 볼륨바의 상태값을 스냅샷)로 해결할 수 있지만, 패닉장에서 2~3분 차이면 가격이 5% 움직일 수 있으므로 이 lag가 치명적입니다.

따라서 **Volume Bar의 통계적 우수성**(Phase 3)과 **시간봉의 횡단면 동기화 장점**(Phase 4)을 각각 살리고, 두 방법의 합의(consensus)로 시그널 신뢰도를 높입니다.

## 2. Phase 3: Volume Bar Grid

### 2.1 이론적 배경

#### Volume Bar (Lopez de Prado, 2018)
**출처**: "Advances in Financial Machine Learning", Ch.2

시간봉(1분, 5분)은 고정 시간 간격으로 봉을 생성합니다. 문제는 장 초반(거래 폭주)과 점심(한산)의 **정보 밀도가 완전히 다르다**는 것입니다. 장 초반 1분에는 수천 건의 체결이 있지만, 점심 1분에는 수십 건밖에 없습니다.

Volume Bar는 **고정 거래량이 채워질 때마다** 봉을 생성합니다. 이러면 봉당 거래량이 동일하므로, 각 봉이 담고 있는 시장 정보량이 균일해집니다. Lopez de Prado는 이렇게 샘플링된 수익률이 IID(독립 동일 분포)에 더 가까워져 통계적 성질이 개선된다고 주장합니다.

```
시간봉: |--1분--|--1분--|--1분--|--1분--|  ← 각 봉의 거래량 제각각
볼륨바: |---V̄---|---V̄---|---V̄---|         ← 각 봉의 거래량 동일, 시간 간격은 제각각
```

```python
def build_volume_bars(df, target_bars_per_day=25):
    """
    1분봉 → Volume Bar 변환
    
    Parameters:
        df: 1분봉 DataFrame (datetime, open, high, low, close, volume, ...)
        target_bars_per_day: 하루 목표 봉 수 (기본 25)
    
    Logic:
        봉 크기 = 일평균 거래량 / 목표 봉 수
        거래량이 누적되어 봉 크기를 넘으면 봉 확정
        
    종목별 자동 설정:
        삼성전자: 일평균 7,600만주 → 봉 크기 약 300만주
        현대위아: 일평균 85만주 → 봉 크기 약 3.4만주
        → 종목 간 봉 수가 비슷해져서 비교 가능
    """
    daily_vol = df.groupby("date")["volume"].sum().mean()
    bar_size = int(daily_vol / target_bars_per_day)
    
    bars = []
    cum_vol = 0; cum_val = 0; cum_ticks = 0
    bar_open = None; bar_high = -np.inf; bar_low = np.inf
    bar_start = None; n_minutes = 0
    
    for _, row in df.iterrows():
        if bar_open is None:
            bar_open = row["open"]
            bar_start = row["datetime"]
        bar_high = max(bar_high, row["high"])
        bar_low = min(bar_low, row["low"])
        cum_vol += row["volume"]
        cum_val += row["value"]
        cum_ticks += row["num_ticks"]
        n_minutes += 1
        
        if cum_vol >= bar_size:  # 고정 거래량 채워지면 봉 확정
            bars.append({
                "datetime": bar_start,
                "datetime_end": row["datetime"],
                "date": row["date"],
                "open": bar_open, "high": bar_high,
                "low": bar_low, "close": row["close"],
                "volume": cum_vol, "value": cum_val,
                "num_ticks": cum_ticks,
                "n_minutes": n_minutes,
                "avg_trade_size": cum_vol / max(cum_ticks, 1),
            })
            # 리셋
            cum_vol = 0; cum_val = 0; cum_ticks = 0
            bar_open = None; bar_high = -np.inf; bar_low = np.inf
            n_minutes = 0
    
    return pd.DataFrame(bars), bar_size
```

### 2.2 BVC (Bulk Volume Classification)

#### 이론적 배경
**출처**: Easley, Lopez de Prado, O'Hara (2012) "Flow Toxicity and Liquidity in a High-frequency World", Review of Financial Studies, Vol.25, pp.1457-1493

VPIN과 주문 불균형을 계산하려면 매수 주도 거래량(V_buy)과 매도 주도 거래량(V_sell)을 정확히 분리해야 합니다. 틱(Tick) 데이터나 호가창(Level 2) 데이터가 있다면 Lee-Ready 알고리즘 등으로 명확히 분류되지만, 1분봉 데이터에서는 1분 내의 체결 내역이 뭉개져 있습니다.

BVC는 1분봉의 가격 변화를 정규분포로 모델링하여 **확률적으로** 매수/매도 비율을 추정합니다. 개별 봉의 분류가 부정확해도 n개 봉을 합산하면 대수의 법칙(Law of Large Numbers)으로 수렴합니다.

두 가지 방법을 병행합니다:

```python
def bvc_cdf(df, window=20):
    """
    방법 A: 정규분포 CDF
    
    V_buy = V × Φ((Close - Open) / σ_ΔP)
    V_sell = V × (1 - Φ(...))
    
    직관:
        양봉(Close > Open) → Φ > 0.5 → 매수 비중 높음
        음봉(Close < Open) → Φ < 0.5 → 매도 비중 높음
        보합(Close = Open) → Φ = 0.5 → 반반
    
    σ_ΔP는 rolling 표준편차로, 당일 변동성에 자동 적응
    """
    delta = df["close"] - df["open"]
    sigma = delta.rolling(window, min_periods=5).std().fillna(delta.std())
    sigma = sigma.clip(lower=1)  # 0 방지
    z = norm.cdf(delta / sigma)
    df["v_buy"] = df["volume"] * z
    df["v_sell"] = df["volume"] * (1 - z)
    return df


def bvc_position(df):
    """
    방법 B: High-Low Position
    
    V_buy = V × (Close - Low) / (High - Low)
    V_sell = V × (High - Close) / (High - Low)
    
    직관:
        종가가 고가 근처 → 매수 우위
        종가가 저가 근처 → 매도 우위
        
    장점: 봉 내 고가/저가 정보를 활용하여 방향성 추정
    폭락장에서 CDF보다 직관적 (저가 근처 마감 = 매도 우위)
    """
    hl = (df["high"] - df["low"]).clip(lower=1)
    pos = (df["close"] - df["low"]) / hl
    df["v_buy_p"] = df["volume"] * pos
    df["v_sell_p"] = df["volume"] * (1 - pos)
    return df
```

### 2.3 Kyle's Lambda

#### 이론적 배경
**출처**: Kyle (1985) "Continuous Auctions and Insider Trading", Econometrica, Vol.53, pp.1315-1336

Kyle 모델에서 λ(lambda)는 **가격 충격 계수(price impact coefficient)**입니다. 시장에 정보 비대칭이 있을 때, 마켓 메이커는 주문 흐름(order flow)을 관찰하고 그에 비례하여 가격을 조정합니다. 이때의 비례 상수가 λ입니다.

```
ΔP = λ × signed_volume + ε
```

- λ가 크면: 거래 한 단위에 가격이 크게 밀림 (시장이 비유동적, 또는 패닉)
- λ가 작으면: 거래해도 가격이 잘 안 움직임 (유동성 풍부)
- λ → 0 수렴: **거래는 되는데 가격이 안 밀림 = 매도 소진**

#### 마이크로 노이즈 방지

Lambda를 **개별 봉**에서 ΔP/V로 계산하면, 특정 1분 동안 거래량이 극단적으로 적을 때 분모가 0에 가까워져 λ 값이 비정상적으로 폭등(∞)합니다. 이는 '매도 클라이맥스'가 아니라 단순한 '호가 공백'임에도 불구하고 Z-score 랭킹을 완전히 망가뜨릴 수 있습니다.

이를 방지하기 위해 **rolling window 회귀**로 추정합니다. window 안에서 거래가 없는 봉은 signed_volume=0, ΔP≈0이므로 회귀에서 원점 근처 관측치로 들어가 λ 추정을 왜곡하지 않습니다.

```python
def kyle_lambda_rolling(prices, volumes, opens, closes, window=20):
    """
    Kyle's Lambda: Rolling 회귀로 추정
    
    모델: ΔP_t = λ × signed_volume_t + ε_t
    추정: λ = Σ(x·y) / Σ(x²)  (OLS without intercept)
    
    signed_volume = volume × sign(close - open)
        양봉: 매수 주도 → 양수
        음봉: 매도 주도 → 음수
    
    마이크로 노이즈 방지:
        - 거래량 0인 봉은 회귀에서 자동 제외 (mask)
        - window 내 유효 봉이 절반 미만이면 이전 값 유지 (자동 평활화)
        - 종목별 window 자동 설정 (거래 적은 종목은 window 확대)
    
    Parameters:
        window: rolling window 크기
            삼성전자: 20 (분당 거래 충분)
            현대위아: 40 (거래 듬성듬성 → 유효 봉 확보)
    """
    dp = prices.diff().fillna(0)
    sv = volumes * np.sign(closes - opens)
    
    lambdas = np.full(len(prices), np.nan)
    for t in range(window, len(prices)):
        y = dp.iloc[t-window:t].values
        x = sv.iloc[t-window:t].values
        
        # 거래량 > 0 인 봉만 사용
        mask = np.abs(x) > 0
        if mask.sum() < window // 2:
            # 유효 봉이 절반 미만 → 이전 값 유지
            lambdas[t] = lambdas[t-1] if t > window else np.nan
            continue
        
        xv = x[mask]; yv = y[mask]
        denom = xv @ xv  # Σ(x²)
        if denom > 0:
            lambdas[t] = (xv @ yv) / denom  # λ = Σ(xy) / Σ(x²)
        else:
            lambdas[t] = lambdas[t-1] if t > window else np.nan
    
    return lambdas
```

### 2.4 VPIN (Volume-Synchronized Probability of Informed Trading)

#### 이론적 배경
**출처**: Easley, Lopez de Prado, O'Hara (2012), Review of Financial Studies

VPIN은 주문 흐름의 **독성(toxicity)**을 측정합니다. 매수 주도 거래와 매도 주도 거래의 불균형이 클수록 VPIN이 높아지고, 이는 누군가가 사적 정보(private information)를 기반으로 매매하고 있다는 뜻입니다.

```
VPIN = Σ|V_buy - V_sell| / (n × V̄)
```

폭락장에서: VPIN 급등 → 정보 비대칭 증가 (패닉 매도 집중)
           VPIN 피크 후 하락 → 정보 비대칭 해소 (매도 소진)

```python
def vpin_rolling(v_buy, v_sell, window=20):
    """
    VPIN: Rolling window로 근사
    
    원래 VPIN은 볼륨 버킷 단위이지만,
    1분봉에서 rolling window로 근사합니다.
    
    마이크로 노이즈 방지:
        window 내 총 거래량이 거의 없으면 이전 값 유지
        → 개별 봉의 거래량 0 문제가 자연 해소
    """
    imbalance = np.abs(v_buy - v_sell)
    total = v_buy + v_sell
    
    vpin = np.full(len(v_buy), np.nan)
    for t in range(window, len(v_buy)):
        total_vol = total.iloc[t-window:t].sum()
        if total_vol < 1:
            vpin[t] = vpin[t-1] if t > window else np.nan
            continue
        vpin[t] = imbalance.iloc[t-window:t].sum() / total_vol
    
    return vpin
```

### 2.5 Amihud Illiquidity Ratio

#### 이론적 배경
**출처**: Amihud (2002) "Illiquidity and stock returns: cross-section and time-series effects", Journal of Financial Markets

Kyle's Lambda의 비모수적(non-parametric) 보완. 회귀 대신 단순 비율로 계산합니다.

```
ILLIQ = |ΔP| / (P × V) = "1원어치 거래당 가격 변화"
```

```python
def amihud_rolling(delta_p_abs, dollar_volume, window=20):
    ratio = delta_p_abs / dollar_volume.clip(lower=1)
    return ratio.rolling(window, min_periods=5).mean()
```

## 3. Phase 4: 1-Min Grid

### 3.1 변수 추출

1분봉 OHLCV에서 5개 변수를 추출합니다. 각 변수는 가격 변화의 서로 다른 측면을 포착합니다.

```python
# 1분봉에서 추출하는 5개 변수
df["delta_p"]   = df["close"].diff().fillna(0)             # 가격 변화
df["delta_v"]   = df["volume"].diff().fillna(0)             # 거래량 변화
df["spread"]    = df["high"] - df["low"]                    # 봉내 스프레드
df["sigma"]     = df["delta_p"].rolling(20, min_periods=5).std()  # 롤링 변동성
df["imbalance"] = (df["close"] - df["open"]) / df["spread"].clip(lower=1)  # 거래 불균형
```

| 변수 | 수식 | 의미 | 폭락장에서 |
|------|------|------|-----------|
| ΔP | Close_t - Close_{t-1} | 가격 변화 | 음수 (하락) |
| ΔV | Volume_t - Volume_{t-1} | 거래량 변화 | 양수 (폭증) |
| S | High - Low | 봉내 스프레드 | 확대 (불확실성) |
| σ | std(ΔP, 20분) | 롤링 변동성 | 급등 (공포) |
| I | (Close-Open)/S | 거래 불균형 | -1에 가까움 (매도 우위) |

### 3.2 Regime Shift 대응 — 3가지 통합

#### 문제: 평시(Peace-time) 기준이 전시(War-time)에서 무의미

과거 3~6개월 데이터를 기준으로 삼으면, 폭락장 전 구간이 "극단적 이상치(Outlier)"로만 표시되어 정작 장중(Intraday)의 미세한 바닥 턴어라운드를 잡아낼 수 없습니다. 전쟁 발발과 같은 강력한 외부 충격으로 시장이 급락하는 구간에서는 기존의 변동성이나 호가창 두께가 무의미합니다.

따라서 과거 데이터를 과감히 버리고, 현재 진행 중인 폭락장 당일(또는 충격이 시작된 시점)의 데이터만으로 기준점을 잡습니다.

#### 대응 (a): EWMA 당일 기준 재설정

```python
# EWMA 기반 당일 기준
# halflife=30분: 30분 전 데이터에 절반의 가중치
for col in ["kyle_lambda", "vpin_cdf", "delta_p", "spread", "sigma"]:
    ewma_base = []
    for d in sorted(df["date"].unique()):
        day = df[df["date"]==d][col]
        ewma = day.ewm(halflife=30, min_periods=5).mean()
        
        # 첫 30분으로 "오늘의 패닉 베이스라인" 설정
        first30 = ewma.iloc[:30]
        base_mean = first30.mean()
        base_std = first30.std()
        
        # 이후 데이터는 베이스라인 대비로 정규화
        normalized = (ewma - base_mean) / max(base_std, 1e-8)
        ewma_base.append(normalized)
    
    df[f"{col}_ewma"] = pd.concat(ewma_base).values
```

**효과**: 오전에 발생한 1차 패닉 셀링의 λ와 VPIN이 새로운 "정상(Normal)" 기준이 됩니다. 오후에 2차 투매가 나올 때 오전에 비해 λ가 얼마나 더 튀는지를 비교하여 진정한 매도 클라이맥스를 포착합니다.

#### 대응 (b): Cross-sectional Z-score (횡단면 상대 비교)

13종목을 과거의 자기 자신과 비교하는 것이 아니라, **현재 시점(t)에서 종목끼리 상대 비교**합니다.

```python
def cross_sectional_zscore(wide_df):
    """
    MAD(Median Absolute Deviation) 기반 Robust Z-score
    
    왜 MAD인가:
        4종목밖에 없으니 1종목이 극단값을 가지면
        일반 Z-score(평균/표준편차)가 불안정해짐.
        MAD는 중앙값 기반이라 극단값에 robust.
    
    수식:
        z = (x - median) / (MAD × 1.4826)
        1.4826은 정규분포 가정 하 MAD→σ 변환 상수
    
    거래 정지 종목 처리:
        상한가/하한가로 거래가 멈춘 종목은 Z-score에서 제외.
        안 그러면 횡단면 분포가 왜곡됨.
    """
    median = wide_df.median(axis=1)
    mad = (wide_df.subtract(median, axis=0)).abs().median(axis=1) * 1.4826
    z = wide_df.subtract(median, axis=0).divide(mad.clip(lower=1e-8), axis=0)
    return z

# 매 분마다 4종목의 각 지표를 횡단면 비교
for indicator in ["kyle_lambda", "vpin_cdf", "delta_p", ...]:
    wide = pd.DataFrame(index=common_times)
    for code in codes:
        wide[code] = all_1min[code].set_index("datetime")[indicator]
    
    z_scores = cross_sectional_zscore(wide)
    
    for code in codes:
        all_1min[code][f"{indicator}_z"] = z_scores[code]
```

**효과**: 방산주로 수급이 몰리며 VPIN이 치솟는 동안, 대형주의 λ가 시장 평균 대비 극단적으로 나빠졌다가 회복되는 찰나의 "상대적 수급 불균형 해소"를 직관적으로 캐치할 수 있습니다.

#### 대응 (c): Adaptive Forgetting Kalman Filter

칼만 필터의 상태 추정식에서 과거 상태를 얼마나 유지할지 결정하는 forgetting factor를 조정하여, 모델이 새로운 관측치를 빠르게 추적하도록 합니다.

**이론적 배경**:
- Kalman (1960) "A New Approach to Linear Filtering and Prediction Problems"
- 관측 방정식: ΔP_t = X_t · β_t + ε_t
- 상태 방정식: β_t = β_{t-1} + η_t (random walk)
- Forgetting factor λ: P_pred = P / λ (λ < 1이면 과거를 빨리 잊음)

**Q matrix vs R matrix 튜닝 문제**:
급락장에서는 모수들이 매우 빠르게 변하므로, 상태 변수가 관측치를 더 민감하게 따라가도록 세팅해야 합니다. Innovation(예측 오차)의 크기에 따라 forgetting factor를 동적으로 조절합니다.

```python
def adaptive_kalman(y, X, forgetting_init=0.92, adapt_window=20):
    """
    Adaptive Forgetting Kalman Filter
    
    핵심: forgetting factor로 과거 데이터의 영향을 조절
        forgetting = 0.95 → 약 20분의 effective memory
        forgetting = 0.85 → 약 6분의 effective memory
    
    Adaptive 조절:
        innovation(예측 오차)이 갑자기 커지면 → regime 변화 감지
        → forgetting을 낮춰서 빠르게 새 regime 적응
        
        innovation이 작아지면 → 안정 구간
        → forgetting을 올려서 노이즈 무시
    
    입력: cross-sectional z-score (raw 값 아님)
        → z-score는 항상 -3~+3 범위라 스케일 안정
        → Q/R 튜닝 문제가 대폭 완화
    """
    T, k = X.shape
    beta = np.zeros(k)          # 상태 벡터 (β 계수들)
    P = np.eye(k) * 1.0         # 상태 공분산
    R = 1.0                     # 관측 노이즈
    forget = forgetting_init
    
    betas = np.zeros((T, k))
    innovations = np.zeros(T)
    
    for t in range(T):
        # 결측 처리
        if np.isnan(y[t]) or np.any(np.isnan(X[t])):
            betas[t] = beta; continue
        
        # Predict — forgetting으로 불확실성 증가
        P_pred = P / forget  # ← 핵심: λ로 나눠서 P를 키움
        
        # Update (Kalman gain 계산)
        x_t = X[t]
        innovation = y[t] - x_t @ beta
        innovations[t] = innovation
        S = x_t @ P_pred @ x_t + R
        K = P_pred @ x_t / max(S, 1e-12)
        
        # 상태 업데이트
        beta = beta + K * innovation
        P = (np.eye(k) - np.outer(K, x_t)) @ P_pred
        betas[t] = beta
        
        # 관측 노이즈 adaptive 업데이트
        R = 0.95 * R + 0.05 * innovation**2
        
        # Forgetting factor adaptive 조절
        if t >= adapt_window:
            recent_var = np.var(innovations[t-adapt_window:t])
            if recent_var > 2 * R:
                # regime 변화 → 빨리 잊어라
                forget = max(0.80, forget - 0.02)
            elif recent_var < 0.5 * R:
                # 안정 → 천천히 잊어라
                forget = min(0.98, forget + 0.01)
    
    return betas, innovations
```

### 3.3 다변수 회귀 — Rolling OLS

**이론적 배경**:
전미분(total differential)으로 가격 변화를 분해합니다:

```
dP = (∂P/∂V)dV + (∂P/∂S)dS + (∂P/∂σ)dσ + (∂P/∂I)dI + (∂P/∂t)dt
```

이걸 cross-sectional z-score 기반으로 추정하면:

```
ΔP_z_t = β₁·ΔV_z_t + β₂·ΔS_z_t + β₃·Δσ_z_t + β₄·ΔI_z_t + α + ε_t
```

Linear Algebra로:

```
β̂_t = (X'_t X_t)⁻¹ X'_t y_t

여기서:
y_t = [ΔP_z_{t-W+1}, ..., ΔP_z_t]'              (W×1 벡터)

X_t = [1   ΔV_z_{t-W+1}  ΔS_z_{t-W+1}  Δσ_z_{t-W+1}  ΔI_z_{t-W+1}]
      [1   ΔV_z_{t-W+2}  ...                                        ]
      [... ...            ...            ...            ...          ]    (W×5 행렬)
      [1   ΔV_z_t        ΔS_z_t        Δσ_z_t        ΔI_z_t        ]

β̂_t = [α_t, β₁_t, β₂_t, β₃_t, β₄_t]'           (5×1 벡터)
```

```python
def rolling_ols(y, X, window=20):
    """
    Rolling OLS — numpy linear algebra
    
    매 시점마다 직전 W분 데이터로 OLS 회귀
    → 각 계수의 시계열이 나옴
    
    2가지 방법 병행:
        Rolling OLS: 빠르고 직관적, Kalman Q/R 초기값 역산용
        Adaptive Kalman: regime 변화에 더 빠르게 반응
        → 두 방법에서 일관된 시그널만 채택
    """
    T, k = X.shape
    betas = np.full((T, k), np.nan)
    
    for t in range(window, T):
        Xw = X[t-window:t]
        yw = y[t-window:t]
        
        # 결측 제거
        mask = ~(np.isnan(Xw).any(axis=1) | np.isnan(yw))
        if mask.sum() < k + 2:
            if t > window: betas[t] = betas[t-1]
            continue
        
        try:
            # β = (X'X)⁻¹X'y
            betas[t] = np.linalg.lstsq(Xw[mask], yw[mask], rcond=None)[0]
        except:
            if t > window: betas[t] = betas[t-1]
    
    return betas
```

### 3.4 β 계수의 해석

| 계수 | 수식 | 의미 | 패닉 중 | 바닥 시그널 |
|------|------|------|---------|-----------|
| β₁ | ∂P/∂V | 거래량→가격 충격 | 음수, 절대값 큼 | β₁ → 0 수렴 (매도 소진) |
| β₂ | ∂P/∂S | 스프레드→가격 | 음수 (불확실성↑→가격↓) | β₂ 절대값 감소 |
| β₃ | ∂P/∂σ | 변동성→가격 | 음수 (변동성↑→가격↓) | β₃ 안정화 |
| β₄ | ∂P/∂I | 수급불균형→가격 | 의미 없음 (혼란) | **β₄ 양수 전환** (핵심) |
| α | ∂P/∂t | 시간 경과 효과 | 음수 (시간만으로 하락) | α 양수 전환 |

**OLS/Kalman의 역할**: 바닥 2~5시간 전에 "패닉 구조가 바뀌고 있다" 감지. 매매 타이밍이 아니라 **대기 모드 진입** 시그널. 정밀 타이밍은 Phase 5의 미분 제로크로싱이 담당.

### 4.1 인과적 필터 선택

#### ⚠️ Look-ahead Bias 수정 (v1→v2)

```python

smoothed = gaussian_filter1d(vals, sigma=15)
```

`scipy.ndimage.gaussian_filter1d`는 중앙 정렬(centered) 가우시안으로, 현재 시점의 좌우 데이터를 모두 사용합니다. 백테스트에서는 미래 데이터가 있으니 작동하지만, **실시간에서는 t+15분이 존재하지 않으므로 작동 불가**합니다.


EMA(Exponential Moving Average)는 현재와 과거 데이터만 사용하는 인과적 필터입니다. span=30은 약 30분의 effective window이며, 최근 데이터에 더 큰 가중치를 부여합니다.

### 4.2 인과적 미분 및 제로크로싱

```python
def compute_derivatives_causal(series, span=30):
    """
    인과적 스무딩 + 1차/2차 미분
    
    EMA로 스무딩 후 np.gradient로 미분.
    EMA가 인과적이므로 전체 파이프라인은 인과적.
    """
    vals = pd.Series(series).interpolate().ffill().bfill().values.astype(float)
    smoothed = pd.Series(vals).ewm(span=span, min_periods=5).mean().values
    d1 = np.gradient(smoothed)    # 1차 미분
    d2 = np.gradient(d1)          # 2차 미분
    return smoothed, d1, d2

def find_zeros_down(deriv):
    """양→음 전환 (극대점)"""
    return [i for i in range(1, len(deriv)) if deriv[i-1] > 0 and deriv[i] <= 0]

def find_zeros_up(deriv):
    """음→양 전환 (극소점)"""
    return [i for i in range(1, len(deriv)) if deriv[i-1] < 0 and deriv[i] >= 0]
```

### 4.3 dP/dV 교차 미분 (인과적)

```python
def cross_derivative_causal(price, volume, span=30):
    """
    dP/dV = (dP/dt) / (dV/dt)  — Chain Rule
    
    인과적 EMA로 스무딩 후 계산.
    
    dP/dV < 0: 거래할수록 가격 하락 (패닉)
    dP/dV = 0: 거래해도 가격 안 움직임 (매도 소진)
    dP/dV > 0: 거래할수록 가격 상승 (매수 유입)
    음→양 전환 = 매도 소진 확인
    
    d(dP/dV)/dt:
        음→양 전환 = dP/dV가 하락을 멈추고 상승 시작
        = 매도 소진 프로세스의 "가속도" 전환
    """
    p_smooth = pd.Series(price).ewm(span=span, min_periods=5).mean().values
    v_smooth = pd.Series(volume).ewm(span=span, min_periods=5).mean().values
    
    dp_dt = np.gradient(p_smooth)
    dv_dt = np.gradient(v_smooth)
    
    with np.errstate(divide='ignore', invalid='ignore'):
        dp_dv = np.where(np.abs(dv_dt) > 1e-10, dp_dt / dv_dt, np.nan)
    
    dp_dv_clean = pd.Series(dp_dv).interpolate().fillna(0).values
    dp_dv_smooth = pd.Series(dp_dv_clean).ewm(span=15, min_periods=3).mean().values
    
    # 1차: dP/dV 음→양
    d1_zeros = find_zeros_up(dp_dv_smooth)
    
    # 2차: d(dP/dV)/dt 음→양
    d_dp_dv = np.gradient(dp_dv_smooth)
    d2_zeros = find_zeros_up(d_dp_dv)
    
    return d1_zeros, d2_zeros, dp_dv_smooth
```

### 4.4 인과적 필터 기반 — 실측 시퀀스

12케이스(4종목 × 3폭락일)의 인과적 필터 결과에서 발견된 순서:

```
인과적(EMA) 기준 평균 순위:

1위: ② d(dP/dV)/dt 음→양     매도소진 가속도 전환       ← 가장 먼저
2위: ② d²σ/dt²=0            변동성 증가 둔화
3위: ① dP/dV 음→양           매도소진 확인
4위: ② d²S/dt²=0            스프레드 확대 둔화
5위: ② d²V/dt²=0            거래량 증가 둔화
6위: ① dσ/dt=0              변동성 피크
7위: ① dS/dt=0              스프레드 피크
8위: ① dV/dt=0              거래량 피크                 ← 가장 마지막
★:   dP/dt=0               가격 바닥
```

**비인과 필터에서는 V(거래량)가 1등이었지만, 인과적 필터에서는 dP/dV가 1등.**
인과적 EMA가 최근 데이터에 높은 가중치를 주기 때문에, 가격-거래량 관계의 변화(dP/dV)가 개별 변수(V, S, σ)의 피크보다 먼저 감지됩니다.

#### 실제 예시: 한미반도체 2026-03-04 (바닥 12:33)

```
11:59  ② d(dP/dV)/dt↑  매도소진 가속도 전환     34분 선행
12:02  ① dP/dV 음→양    매도소진 확인            31분 선행
12:18  ② d²V/dt²=0     거래량 증가 둔화          15분 선행
12:19  ① dV/dt=0       거래량 피크               14분 선행
12:24  ② d²S/dt²=0     스프레드 확대 둔화          9분 선행
12:24  ② d²σ/dt²=0     변동성 증가 둔화            9분 선행
12:25  ① dS/dt=0       스프레드 피크               8분 선행
12:25  ① dσ/dt=0       변동성 피크                 8분 선행
12:33  ★ 가격 바닥
```

### 4.5 d²→d¹ 시차: 2분이 정상인 이유 (v3 수정)

비인과 필터에서 18분이었던 d²→d¹ 시차가 인과적 필터에서 **2분**으로 축소되었습니다.

1. **18분이 가짜였습니다.** `gaussian_filter1d(sigma=15)`는 뾰족한 피크를 인위적으로 넓게 펴놓습니다. 원래 뾰족한 산을 밀대로 눌러 완만한 언덕으로 만들면, 변곡점과 꼭대기 사이가 당연히 멀어집니다. 비인과 필터의 sigma=15는 약 30분의 데이터를 양방향으로 평균내는 효과이므로, 실제로는 15분 너비의 아티팩트가 생깁니다.

2. **2분이 실제 시장의 형태에 부합합니다.** 폭락장에서 거래량이나 변동성은 폭발적으로 치솟다가 급격히 꺾입니다. 이런 뾰족한 피크에서 변곡점(d²=0)과 극점(d¹=0)은 가까운 게 정상입니다.

3. **실전에서 2분이면 충분합니다.** ②가 나오면 "①이 2분 내에 온다"는 확인이고, 매수 주문 준비(수량 결정, 주문 입력)를 할 시간으로 충분합니다. 시간을 카운트다운하는 게 아니라, **체크리스트를 하나씩 채워가는 방식**입니다.

### 4.7 OLS vs Kalman 교차 검증

두 가지 독립적 방법으로 같은 시그널을 감지하면 신뢰도가 높아집니다.

```python
def cross_validate_signals(ols_signals, kal_signals, max_diff=30):
    """
    OLS와 Kalman 양쪽에서 감지된 시그널만 채택
    
    HIGH:   양쪽 감지 + 시차 30분 이내
    MEDIUM: 양쪽 감지 + 시차 30분 초과
    LOW:    한쪽만 감지
    """
    consensus = {}
    all_names = set(list(ols_signals.keys()) + list(kal_signals.keys()))
    
    for sn in all_names:
        ols_idx = ols_signals.get(sn)
        kal_idx = kal_signals.get(sn)
        
        if ols_idx is not None and kal_idx is not None:
            diff = abs(ols_idx - kal_idx)
            avg_idx = (ols_idx + kal_idx) // 2
            confidence = "HIGH" if diff <= max_diff else "MEDIUM"
            consensus[sn] = {"idx": avg_idx, "confidence": confidence}
        elif ols_idx is not None:
            consensus[sn] = {"idx": ols_idx, "confidence": "LOW"}
        elif kal_idx is not None:
            consensus[sn] = {"idx": kal_idx, "confidence": "LOW"}
    
    return consensus
```

## 6. 확률적 확장: Stochastic Differential Equation

### 6.1 현재 모델의 한계: 순수 결정론적

현재 파이프라인은 EMA 스무딩 → 미분 → 제로크로싱 탐지로, **확률이 없습니다.** "dP/dV가 0을 넘었다/안 넘었다"의 이진 판단만 가능합니다.

문제:
- dP/dV가 -0.001인데 이게 곧 0을 넘을지, 더 내려갈지 모름
- 노이즈 때문에 0을 잠깐 넘었다가 다시 내려가는 거짓 시그널 구분 불가
- "10분 내에 바닥" vs "30분 내에 바닥"의 확률적 구분 불가

### 6.2 Kyle 원래 모델의 확률 구조

Kyle (1985) 원래 모델에서 가격은 Brownian motion을 따릅니다:

```
dP_t = λ · (x_t · dt + σ_u · dW_t) 
       ↑ price impact  ↑ informed  ↑ noise (Brownian)
```

우리가 Kyle's Lambda를 쓰면서 정작 **확률 구조(dW)는 빠뜨린** 겁니다.

### 6.3 SDE 모델 제안

현재 결정론적 모델을 SDE(Stochastic Differential Equation)로 확장:

**가격 프로세스:**
```
dP = β₁dV + β₂dS + β₃dσ + β₄dI + αdt + σ_P · dW_P
```

**dP/dV 프로세스** (핵심 시그널):
```
d(dP/dV) = μ(t)dt + σ_ratio · dW_ratio
```

여기서 μ(t)는 dP/dV의 드리프트(추세), σ_ratio는 변동성, dW는 Wiener process (Brownian motion).

### 6.4 확률적 제로크로싱 예측

dP/dV가 현재 값 x₀에서 출발하여 0을 처음 통과하는 시간(First Passage Time)의 분포를 구합니다.

**Inverse Gaussian 분포** (Brownian motion with drift의 first passage time):

```
τ ~ InverseGaussian(μ_τ, λ_τ)

μ_τ = |x₀| / |μ|          (평균 도달 시간)
λ_τ = x₀² / σ²           (형상 모수)

P(τ ≤ t) = Φ(√(λ_τ/t)(t/μ_τ - 1)) + exp(2λ_τ/μ_τ) · Φ(-√(λ_τ/t)(t/μ_τ + 1))
```

```python
from scipy.stats import norm

def predict_zero_crossing(current_value, drift, volatility, max_minutes=60):
    """
    dP/dV가 현재 current_value에서 0까지 도달하는 시간의 확률 분포
    
    이론: Brownian motion with drift의 First Passage Time
          = Inverse Gaussian 분포
    
    Parameters:
        current_value: 현재 dP/dV 값 (음수이면 0까지 올라가야 함)
        drift: dP/dV의 최근 변화 추세 (EMA of gradient)
        volatility: dP/dV의 최근 변동성 (rolling std)
        max_minutes: 최대 예측 범위
    
    Returns:
        prob_by_minute: 각 분까지 0을 통과할 누적 확률
    """
    if current_value >= 0:
        return np.ones(max_minutes)  # 이미 양수
    
    x0 = abs(current_value)
    
    if abs(drift) < 1e-10 or volatility < 1e-10:
        return np.zeros(max_minutes)
    
    mu_tau = x0 / abs(drift)
    lambda_tau = x0**2 / volatility**2
    
    if mu_tau <= 0 or lambda_tau <= 0:
        return np.zeros(max_minutes)
    
    minutes = np.arange(1, max_minutes + 1)
    probs = np.zeros(max_minutes)
    
    for i, t in enumerate(minutes):
        if t <= 0: continue
        term1 = np.sqrt(lambda_tau / t) * (t / mu_tau - 1)
        term2 = np.sqrt(lambda_tau / t) * (t / mu_tau + 1)
        p = norm.cdf(term1) + np.exp(2 * lambda_tau / mu_tau) * norm.cdf(-term2)
        probs[i] = min(p, 1.0)
    
    return probs


def realtime_signal(dp_dv_series, window=20):
    """
    실시간 시그널: dP/dV가 0을 넘을 확률
    
    매 분마다:
    1. 현재 dP/dV 값
    2. 최근 drift (EMA of gradient)
    3. 최근 volatility (rolling std)
    → Inverse Gaussian으로 "N분 내 0 통과 확률" 계산
    """
    T = len(dp_dv_series)
    prob_10min = np.full(T, np.nan)
    prob_30min = np.full(T, np.nan)
    
    for t in range(window, T):
        current = dp_dv_series[t]
        
        if current >= 0:
            prob_10min[t] = 1.0; prob_30min[t] = 1.0; continue
        
        recent = dp_dv_series[t-window:t]
        gradient = np.gradient(recent)
        drift = pd.Series(gradient).ewm(span=10).mean().iloc[-1]
        vol = pd.Series(recent).diff().std()
        
        if drift <= 0:
            prob_10min[t] = 0.05; prob_30min[t] = 0.1; continue
        
        probs = predict_zero_crossing(current, drift, vol, 60)
        prob_10min[t] = probs[9] if len(probs) > 9 else 0
        prob_30min[t] = probs[29] if len(probs) > 29 else 0
    
    return prob_10min, prob_30min
```

### 6.5 확률적 시그널의 활용

```
결정론적 (현재):
  "dP/dV가 0을 넘었다" → 매수

확률적 (v3):
  "dP/dV가 10분 내 0을 넘을 확률 30%" → 아직 대기
  "dP/dV가 10분 내 0을 넘을 확률 60%" → 매수 준비 (주문 입력)
  "dP/dV가 10분 내 0을 넘을 확률 85%" → 매수 실행
  "dP/dV가 0을 넘음 + 확률이 90% 이상 유지 5분" → 확정 (거짓 시그널 필터)
```

**거짓 시그널 필터**: 노이즈로 dP/dV가 잠깐 0을 넘었다가 다시 내려가면, 확률이 90% 이상 "유지"되지 않습니다. 확률이 올라갔다 내려가면 거짓 시그널로 판단하고 무시.

### 6.6 Brownian Motion 기반 β 계수 모델링

Kalman Filter의 상태 방정식에 Brownian motion을 명시적으로 추가:

```
현재 (Random Walk):
  β_t = β_{t-1} + η_t,  η_t ~ N(0, Q)

확장 (Ornstein-Uhlenbeck / 평균 회귀):
  dβ_t = κ(θ - β_t)dt + σ_β · dW_t
  
  κ: 평균 회귀 속도 (패닉 중 빠르게, 안정 시 느리게)
  θ: 장기 평균 (β₁의 경우 0에 가까움)
  σ_β: β의 변동성 (= Q의 대각 성분)
```

이러면 β₁이 0에 수렴하는 것이 단순 관측이 아니라 **평균 회귀 프로세스**로 모델링됩니다. "β₁이 0으로 돌아오는 속도(κ)가 빨라졌다"는 것 자체가 매도 소진 시그널이 됩니다.

## 7. 전략적 함의

### 7.1 전체 매매 시퀀스 (v3)

OLS/Kalman이 **"언제부터 주의를 기울여야 하는가"**를 알려주고, 미분 제로크로싱이 **"지금 사라"**를 알려주는 구조입니다.

```
[대기 모드] OLS/Kalman β₄ 양수 전환 (바닥 2~5시간 전)
  → "패닉 구조가 바뀌기 시작. 아직 사지 마라."

[경계 모드] dP/dV 0 통과 확률 > 30% (바닥 약 30~40분 전)
  → "매도소진 프로세스 진행 중"

[준비 모드] dP/dV 0 통과 확률 > 60% + ②d²V/dt²=0 (바닥 약 10~15분 전)
  → "체크리스트 진행, 주문 입력"

[실행] dP/dV 음→양 확정 + 확률 90% 이상 5분 유지 (바닥 약 3~10분 전)
  → "매수 실행"

[확인] dP/dt 양수 전환
  → "바닥 확인. 추가 매수 또는 홀드."
```

### 7.2 체크리스트 방식

시간을 카운트다운하는 게 아니라 시그널이 순서대로 나오는 걸 확인합니다. ②가 나오면 ①이 곧 온다는 확인(2분 내). 어떤 날은 ②→①이 빠르고 어떤 날은 느리지만, **순서는 일관적**입니다.

```
□ OLS/Kalman β₄ 양수 전환                → ☑ 대기 모드
□ dP/dV 0통과 확률 > 30%                 → ☑ 경계 모드
□ ② d(dP/dV)/dt 음→양 (소진 가속)         → ☑ 확인 1
□ ② d²σ/dt²=0 (변동성 둔화)              → ☑ 확인 2
□ ① dP/dV 음→양 (매도소진)               → ☑ 준비
□ ① dV/dt=0 + ① dσ/dt=0 (피크 확인)     → ☑ 매수 실행
□ dP/dt 양수 전환 (가격 반등)              → ☑ 확정
```

가장 보수적으로 하려면 dP/dV 음→양도 기다리지 않고, **dP/dt가 실제로 양수 전환**(가격이 반등 시작)한 후에 사는 것. 바닥 대비 약간 늦지만 "떨어지는 칼"을 잡을 확률이 0에 가까워집니다.

### 7.3 종목 간 선행/후행 활용

일봉 분석(Phase 1)과 분봉 분석(Phase 3~5)의 결합:

- **일봉**: 반등일에 시총 클수록 반등 큼. 삼전·닉스·한미반도체 반등 상위. 승률 99%.
- **분봉**: 중대형 고변동주(현대위아·한미반도체)가 대형주(삼전·닉스)보다 **먼저 바닥**.

3/4: 현대위아 12:34 바닥 vs 삼전 15:19 바닥 = 약 3시간 선행.

**전략**: 고변동주의 시그널을 대형주의 매수 타이밍으로 사용. 고변동주가 선행지표, 대형주/ETF가 매매 대상.

### 7.4 한계 및 주의사항

1. **표본 크기**: 4종목 × 3일 = 12케이스. 통계적 신뢰도 부족. 13종목으로 확장 필요.
2. **dP/dV 선행 시간 가변적**: 4~153분으로 범위가 넓음. "몇 분 후 바닥"을 정확히 예측 불가.
3. **확률 모델 미검증**: Inverse Gaussian first passage time은 이론적 유도. 실측 분포 적합도 검증 필요.
4. **매도 타이밍 미분석**: 바닥 탐지만 했고, 반등 후 매도 시점은 별도 분석 필요.
5. **EMA span 민감도**: span=30 고정. 최적값 탐색 및 민감도 분석 필요.
6. **하루 -12% 폭락은 극히 드문 이벤트**: 다른 폭락 사례에서의 검증 기회 부족.
7. **거짓 시그널**: 인과적 필터에서 제로크로싱이 더 자주 발생할 수 있음. 확률적 필터(6장)로 보완 필요.
