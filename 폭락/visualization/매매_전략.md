# 폭락장 반등 스캘핑 전략 — "감속 매수, 가속 매도"

## 전략 요약

폭락장에서 가격이 하락하다가 감속하는 순간에 매수하고, 반등이 다시 꺾이기 전에 매도하는 장중 단타 전략.

**백테스트 결과** (4종목 × 6일, 비용 0.16% 포함):
- 170회 매매, 승률 41.8%, 거래당 +0.152%, 누적 **+25.78%**
- 손익비 2.0x (이기면 +1.22%, 지면 -0.62%)
- 48개 파라미터 조합 **전부** 양수 수익
- Break-even 비용: 편도 0.31%까지 수익 유지

## 1장. 전략을 어떻게 만들었는가 — 연구 과정

### 1.1 출발점: "폭락장에서 장중 바닥을 잡을 수 있는가?"

미·이란 전쟁(2026.03.03) 이후 한국 증시 6일간의 1분봉 데이터(4종목)를 분석. 처음에는 "바닥을 정확히 찾자"는 접근이었으나, 여러 단계를 거쳐 "바닥을 맞추지 말고, 매 반등마다 짧게 먹고 빠지자"로 전환.

### 1.2 실패한 접근들

#### (a) 결정론적 제로크로싱 (Phase 5)
dP/dV(가격-거래량 교차 미분)가 음→양 전환하는 시점을 바닥으로 판정.
- **결과**: 바닥 33분 전 시그널, 감지율 100%
- **문제**: 장 초반에 이미 시그널 발생 → 바닥 150~360분 선행 → 너무 일찍

#### (b) Inverse Gaussian / Monte Carlo 확률 모델
dP/dV가 0을 통과할 확률을 Brownian motion First Passage Time으로 계산.
- **결과**: IG와 MC가 거의 동일 (차이 0.01~0.02)
- **문제**: 하루 4~21회 거짓 시그널. 확률만으로 진짜/가짜 구분 불가

#### (c) 체크리스트 + 확률 + 포지션 사이징 통합
결정론적 체크리스트가 완료된 시점에서만 확률을 참조.
- **문제**: 체크리스트 항목들이 장 시작 직후에 이미 3~5개 완료 → 여전히 너무 일찍

#### (d) 매도 에너지 소진 모델
volume × velocity²를 "매도 에너지"로 정의하고 소진 정도를 추적.
- **결과**: 거짓 시그널 0~1회로 대폭 감소
- **문제**: 바닥 시점에서 에너지가 오히려 최대 → 바닥 **후**에야 소진 확인 가능

### 1.3 전환: "바닥 맞추기" → "반등 파도 타기"

핵심 깨달음: 폭락일에도 하루 내내 빠지는 게 아니라 **투매→반등→재투매가 반복**된다.

6일 전체를 Intraday Micro-Regime으로 분류한 결과:
- 폭락일 평균 15.2회 투매 사이클
- 반등일에도 10.2회 투매 사이클
- 폭락→반등 전환 124회, 반등→폭락 전환 176회

**각 전환마다 1% 먹고 빠지면 되지 않나?**

### 1.4 패턴 발견: 전환점에서 변수가 어떻게 움직이는가

124개의 "폭락→반등" 전환점과 81개의 "폭락→횡보" 전환점을 비교하여, **어떤 변수가 두 상황을 구분하는지** Cohen's d (Effect Size)로 측정.

발견된 2개의 핵심 변수:

| 순위 | 변수 | Effect Size | 의미 |
|:---:|------|:---:|------|
| 1 | **가속도 끝값** | **0.872** (강한 구분) | 반등 직전에 가속도가 양수 전환 |
| 2 | **속도 끝값** | **0.589** (중간 구분) | 아직 하락 중이지만 속도가 줄어듦 |

마찬가지로 176개의 "반등→폭락" 전환점을 분석하여 매도 시그널의 핵심 변수 발견:

| 순위 | 변수 | Effect Size | 의미 |
|:---:|------|:---:|------|
| 1 | 10분방향성 | 0.444 | 반등 직전에 양봉 비율 감소 |
| 2 | 가속도 끝값 | 0.431 | 반등 속도가 둔화 |
| 3 | 거래량속도 | 0.341 | 새 매도세 유입으로 거래량 증가 |
| 4 | 스프레드속도 | 0.336 | 불확실성 증가로 스프레드 확대 |

### 1.5 패턴을 전략으로: 파라미터 민감도 검증

발견된 패턴을 매매 규칙으로 변환한 후, 48개 파라미터 조합에서 **전부 양수 수익**을 확인. 이는 패턴 자체가 유효하다는 강한 증거.

## 2장. 시그널 계산 — 수학적 정의

### 2.1 입력 데이터

매 분(t)마다 OHLCV:
- O_t (시가), H_t (고가), L_t (저가), C_t (종가), V_t (거래량)

### 2.2 가격 속도 (vel_ema)

1분 수익률의 지수이동평균.

```
raw_vel_t = (C_t - C_{t-1}) / C_{t-1} × 100   (단위: %/분)

vel_ema_t = EMA(raw_vel, span=5)
```

EMA의 가중치: α = 2/(span+1) = 2/6 ≈ 0.333

해석:
- vel_ema = -0.10: 1분당 0.1%씩 하락 중 (10분이면 약 1% 하락)
- vel_ema = +0.05: 1분당 0.05%씩 상승 중
- vel_ema ≈ 0: 보합 (방향 전환 중이거나 횡보)

### 2.3 가격 가속도 (acc_ema)

속도의 시간 미분.

```
raw_acc_t = d(vel_ema) / dt ≈ vel_ema_t - vel_ema_{t-1}   (np.gradient 사용)

acc_ema_t = EMA(raw_acc, span=5)
```

해석:
- vel < 0, acc > 0: **"빠지지만 감속 중"** → 매수 시그널
- vel > 0, acc < 0: **"오르지만 감속 중"** → 매도 시그널

물리학 비유: 위로 던진 공이 최고점에 도달하기 직전에 속도는 양수이지만 가속도(중력)는 음수. 우리 전략은 이 "꺾이기 직전"의 순간을 포착.

### 2.4 거래량 속도 (vol_vel)

```
vol_ema_t = EMA(V_t, span=10)
vol_vel_t = (vol_ema_t - vol_ema_{t-1}) / vol_ema_{t-1} × 100   (단위: %/분)
```

해석:
- vol_vel > 0: 거래량 증가 중
- 반등→폭락 전환 시: 새 매도세가 유입되면서 거래량이 증가

### 2.5 스프레드 속도 (spr_vel)

```
spread_t = H_t - L_t
spr_ema_t = EMA(spread_t, span=10)
spr_vel_t = (spr_ema_t - spr_ema_{t-1}) / spr_ema_{t-1} × 100
```

해석:
- spr_vel > 0: 가격 변동폭 확대 중 (불확실성 증가)
- 반등→폭락 전환 시: 스프레드가 확대되면서 새로운 하락 준비

### 2.6 10분 방향성 (dir10)

```
direction_t = sign(C_t - C_{t-1})   → +1, -1, 0
dir10_t = Σ(direction_{t-9} ~ direction_t)   → -10 ~ +10
```

해석:
- dir10 = +8: 최근 10분 중 8분이 양봉 (강한 상승 추세)
- dir10 = +0.24: 거의 반반 (반등 모멘텀 약화) → 매도 시그널의 핵심 조건

## 3장. 매매 규칙

### 3.1 매수 진입 — "감속 매수"

세 가지 조건이 **동시에** 충족될 때 매수:

```
조건 ①: acc_ema_t > +0.020     (가속도가 양수 = 감속 중)
조건 ②: vel_ema_t < -0.05      (속도가 아직 음수 = 하락 중)
조건 ③: 직전 5분 중 3분 이상 vel < 0  (하락 추세 확인)
```

**조건 ①+②의 조합이 핵심**:
"아직 빠지고 있지만, 빠지는 속도가 줄고 있다"

이 조합의 Effect Size가 0.872로 "폭락→반등" 전환과 "폭락→횡보" 전환을 강하게 구분.

조건 ③은 노이즈 필터. 단순히 횡보 중에 acc가 올라가는 경우를 배제.

### 3.2 매도 청산 — "가속 매도" + 리스크 관리

5가지 조건 중 **하나라도** 충족 시 매도:

**(A) 패턴 매도** (보유 2분 이상):
```
acc_ema_t < -0.005   AND
dir10_t < +1.0       AND
vol_vel_t > 0        AND
spr_vel_t > 0
```
4가지 조건이 동시에 충족 = "아직 오르지만 모멘텀 약화 + 새 매도세 유입"

**(B) 목표 수익 도달**: 수익률 ≥ +2.0% → 즉시 매도

**(C) 손절**: 수익률 ≤ -0.8% → 즉시 매도

**(D) 시간 초과**: 보유 20분 경과 → 무조건 매도

**(E) 장 마감**: 15:19 이후 → 무조건 매도

### 3.3 쿨다운

매도 후 3분간 재진입 금지. 같은 노이즈에 연속 진입하는 것을 방지.

## 5장. 수익의 원천 — 왜 이 전략이 작동하는가

### 5.1 수익 구조

| 청산 사유 | 건수 | 누적 (비용후) | 역할 |
|-----------|:---:|:---:|------|
| **목표도달(+2%)** | 30 | **+65.9%** | 수익의 전부 |
| 시간초과(20분) | 18 | +4.4% | 소폭 기여 |
| 패턴매도 | 87 | -16.6% | 소폭 손실 방어 |
| 손절(-0.8%) | 26 | -29.1% | 주요 비용 |

구조: **큰 반등 30번이 전체 수익을 만들고, 나머지 140번은 소폭 손실로 방어**. 승률(42%)보다 손익비(2.0x)가 전략을 움직이는 핵심.

### 5.2 왜 "가속도"인가

가격 속도(vel)가 0을 넘는 순간을 기다리면 이미 늦음. 가속도(acc)가 양수로 전환되는 순간은 **속도가 아직 음수일 때** 발생하므로, 가격이 실제로 반등하기 **전에** 진입 가능.

이는 물리학의 운동 법칙과 동일:
- 위치(가격): 아직 하락 중
- 속도(vel): 음수이지만 절대값이 줄어드는 중
- 가속도(acc): **양수로 전환** = 힘의 방향이 바뀜

가속도가 양수 전환된 후 속도가 0을 넘기까지 보통 2~5분. 이 시간이 진입 여유.

### 5.3 왜 "4개 조건 매도"인가

단일 조건(예: acc < 0만)으로 매도하면 노이즈에 너무 빨리 청산. 4개 조건(acc↓ + dir10↓ + vol↑ + spr↑)을 동시에 요구하면:
- 가속도 음수: 반등 모멘텀 약화
- 방향성 약: 양봉이 줄어듦
- 거래량 증가: **새로운 참여자(매도세)가 유입**
- 스프레드 확대: **불확실성 증가**

이 4가지가 동시에 일어나는 건 "단순 휴식"이 아니라 "새 하락파 시작"의 강한 시그널.

## 6장. 한계 및 주의사항

### 6.1 표본 크기
4종목 × 6일 = 24종목-일, 170회 매매. 통계적으로 충분하지 않음. 13종목 확장 및 다른 폭락 사례(2020.03 코로나, 2022.06 금리인상) 검증 필요.

### 6.2 변동성 의존
이 전략은 **변동성이 큰 날에 특화**. 3/10(반등일, 변동성 작음)에서는 비용 후 -0.27%로 유일한 마이너스.

### 6.3 종목 편향
한미반도체(60회, +15.79%)가 전체 수익의 61%를 차지. 대형주(삼성전자)에서는 수익이 상대적으로 작음.

### 6.4 슬리피지 추정
1분봉의 close 기준으로 백테스트했지만, 실제 체결은 bid/ask 스프레드 내에서 이루어짐. 폭락장에서는 스프레드가 평시의 2~5배로 확대되므로 슬리피지가 커질 수 있음.

### 6.5 EMA span 고정
vel span=5, acc span=5를 고정. 종목별/변동성별 적응형 span이 성능을 개선할 수 있으나 과적합 위험.

### 6.6 비현실적 가정
- 원하는 가격에 즉시 체결된다고 가정 (실제로는 호가 대기 필요)
- 시장 충격(market impact) 미고려 (대량 주문 시 자체적으로 가격을 움직일 수 있음)
- 동시에 여러 종목 매매 시 주의력 분산 미고려

## 7장. 실전 적용 가이드

### 7.1 필요 환경
- Bloomberg Terminal 또는 KRX 실시간 1분봉 데이터
- Python 3.8+ (pandas, numpy)
- 주문 API 연동 (선택)

### 7.2 전날 준비
1. 대상 종목 선정: 전일 낙폭 상위 종목 중 거래대금 상위
2. 종목별 평균 스프레드 확인 → 슬리피지 추정치 업데이트

### 7.3 장중 운용
1. 장 시작 후 15분간 시그널 무시 (워밍업)
2. `RealtimeMonitor` 클래스 사용하여 매 분 시그널 확인
3. 매수 시그널 발생 시 즉시 시장가 주문 (지정가는 체결 지연 위험)
4. 매도 시그널/손절/목표 도달 시 즉시 시장가 청산

### 7.4 하지 말아야 할 것
- "이번엔 더 오를 것 같다"며 목표(+2%) 위로 보유 연장 → 데드캣에 걸림
- "조금만 더 기다리면 손절 안 해도 될 것 같다"며 손절 지연 → 폭락에 물림
- 횡보일에 강제로 매매 → 비용만 누적
